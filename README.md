# kcbalusu.com

Built by GitHub Pages (Jekyll) from `main`.

## Writing a post

Add `_posts/YYYY-MM-DD-slug.md`:

```markdown
---
title: The post title
description: One sentence for link previews.
---

Markdown body.
```

It appears at `/blog/slug/`, on the homepage, at `/blog/` and in `/feed.xml`.
For a post published elsewhere, add `external_url:` and `venue:` and leave the body empty.
